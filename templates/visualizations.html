What are we visualizing?

The CNN converts every X-ray image into an embedding vector. In this project, each image embedding has {{ visualization_data.embedding_size }} numerical values.

Since humans cannot directly see a high-dimensional vector space, we use PCA to reduce the embeddings to 2D and 3D visual representations.

2D PCA Visualization

Each point represents one X-ray image. Points that are close together have similar CNN embeddings. This plot reduces the original high-dimensional embeddings to two principal components.

Interactive 3D PCA Visualization

This plot uses three PCA components as X, Y, and Z coordinates. You can rotate, zoom, pan, and hover over the points.

The explanation behind PCA plots

The original CNN embeddings are high-dimensional vectors and cannot be visualized directly. PCA reduces these vectors to fewer dimensions while preserving the most important variation. The 2D and 3D plots help us understand how NORMAL and PNEUMONIA radiographs are distributed in the embedding space.
