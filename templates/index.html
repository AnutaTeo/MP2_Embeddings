1. Image Embedding

Each X-ray is transformed into a numerical vector using a CNN model. This vector is called an image embedding.

2. Similarity Search

The uploaded X-ray embedding is compared with stored dataset embeddings using cosine similarity.

3. Class Estimation

The app checks whether the closest images are mostly NORMAL or PNEUMONIA.
